# Excalidraw diagrams

One folder per problem (folder name = the problem's slug), one file per version:

```
excalidraw/
  design-a-url-shortener/
    v1.0.excalidraw
    v1.1.excalidraw
```

- Bump the minor version (`v1.1`) for tweaks, the major version (`v2.0`) for a redesign. Never overwrite an old version.
- Open or edit any file at https://excalidraw.com (File → Open), then save it back with the next version number.
